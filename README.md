Sistema de Jogadores

Sistema web desenvolvido em Java com Spring Boot.

Funcionalidades:
- Listar jogadores
- Adicionar novo jogador
- Editar jogador
- Visualizar jogador
- Excluir jogador

Tecnologias utilizadas:
- Spring Boot
- Spring Web
- Spring Data JPA
- Thymeleaf
- H2 Database
